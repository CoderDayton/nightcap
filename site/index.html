Nightcap

Play Roblox on Linux like it was made for your PC. Nightcap is Mocktail, tuned to feel fast and look sharp.

Download AppImage Install with Flatpak

AppImage

chmod +x Nightcap-x86_64.AppImage ./Nightcap-x86_64.AppImage

Flatpak

flatpak install --user https://coderdayton.github.io/nightcap/nightcap.flatpakref flatpak run io.github.CoderDayton.nightcap

Build from source

git clone --recurse-submodules https://github.com/CoderDayton/nightcap.git cd nightcap && make build ./build/mocktail

What's different

  • Lower input lag. Frames are shown as soon as they are ready.
  • Sharper textures, with your own PNG overrides if you want them.
  • ETC2 textures render correctly on desktop GPUs.
  • No more error 319 kicks after joining a server.
  • Roblox sees your real RAM and screen size.
