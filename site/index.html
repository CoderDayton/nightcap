Nightcap

Play Roblox on Linux like it was made for your PC. Nightcap is Mocktail, tuned to feel fast and look sharp.

Download AppImage Install with Flatpak

Install

AppImage
chmod +x Nightcap-x86_64.AppImage
./Nightcap-x86_64.AppImage
Flatpak
flatpak install --user https://coderdayton.github.io/nightcap/nightcap.flatpakref
flatpak run io.github.CoderDayton.nightcap
DEB, RPM, pacman
sudo apt install ./nightcap_<version>-1_amd64.deb
sudo dnf install ./nightcap-<version>-1.x86_64.rpm
sudo pacman -U nightcap-<version>-1-x86_64.pkg.tar.zst
Source
git clone --recurse-submodules https://github.com/CoderDayton/nightcap.git
cd nightcap && make build
./build/mocktail

What's different

Input lag
Lower. Frames are shown as soon as they are ready.
Textures
Sharper, with your own PNG overrides if you want them.
ETC2
Textures render correctly on desktop GPUs.
Error 319
No more kicks after joining a server.
RAM and screen
Roblox sees your real RAM and screen size.
