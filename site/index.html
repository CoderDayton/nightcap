Roblox on Linux, tuned for desktop play

Nightcap

A Mocktail fork that keeps up with Roblox updates, with extra bug fixes, custom assets and more.

Download AppImage Install with Flatpak

Install

AppImage
chmod +x Nightcap-x86_64.AppImage
./Nightcap-x86_64.AppImage
Flatpak
flatpak install --user https://coderdayton.github.io/nightcap/nightcap.flatpakref
flatpak run io.github.CoderDayton.nightcap
DEB, RPM, pacman
sudo apt install ./nightcap_<version>-1_amd64.deb
sudo dnf install ./nightcap-<version>-1.x86_64.rpm
sudo pacman -U nightcap-<version>-1-x86_64.pkg.tar.zst
Source
git clone --recurse-submodules https://github.com/CoderDayton/nightcap.git
cd nightcap && make build
./build/mocktail

What's different

Roblox updates
New Roblox versions work soon after they come out.
More games
Answers a server check some experiences use, so you can play those too.
Voice chat
Your microphone still works after a Roblox update.
Login
Verification checks and captchas finish instead of hanging.
Look
The new home screen and side menu, like on Windows.
Your own assets
Drop in your own cursors, fonts and skies. The folder layout matches Sober's.
Mouse and CPU
Optional raw mouse input, and less CPU use while idle.
